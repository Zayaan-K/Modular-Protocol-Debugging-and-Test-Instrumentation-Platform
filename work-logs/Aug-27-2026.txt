2. Add the ESD array

USB female connector → ESD protection → 0 Ω links → USB male connector

Keep these schematic intentions clear:

One protected channel for D+
One protected channel for D−
Very short ESD ground connection
No crossed polarity or channel names
No separate decoupling capacitor unless the selected part’s datasheet explicitly requires one

A normal passive TVS/ESD array generally does not require a decoupling capacitor.

3. Resolve the data-line test points 

Avoid ordinary large through-hole test points on D+ and D−. They introduce extra pad capacitance and an impedance discontinuity even when there is no long branch.

Use one of these approaches:

Small SMD probe pads placed directly in line and symmetrically on both signals, or
Clearly marked optional/DNP probing footprints, or
Omit D+/D− test points and retain only VBUS and ground test points

Keep accessible test points for:

VBUS
Ground
Current-measurement nodes, if already included

Connector shields follow the documented shield strategy
ESD channels and ground match the component datasheet
Optional parts are marked DNP
J3 pin names agree with the base-board interface requirements

Do not need logic-rail decoupling yet if the module contains no powered ICs. Add decoupling later beside each powered active component after its supply voltage is chosen.

Both USB connectors
ESD array
0 Ω links
VBUS fuse or protection placeholder
VBUS and ground test points
Base-board connector
Mounting holes, if already defined

Open the footprint viewer and confirm that the USB connector pad numbering matches its datasheet—not merely the schematic symbol.

Success test

Complete when:

The ESD component has a verified datasheet and footprint.
Every connector pad number has been manually checked.
D+/D− have no large or asymmetric probing branches.
USB VBUS and base-board power cannot unintentionally power each other.
ERC reports no unexplained errors.
You can trace all four USB conductors from one connector to the other.
